# Handouts (not app code)

Files the gym needs outside the app:

- `smsgate-v1.78.2-release.apk` — install on the gym Android phone. This is the
  SMSGate app that sends gym SMS through the phone's SIM. Keep the phone on,
  online, and logged into the same SMSGate cloud account saved in
  Settings → SMS Notifications.
- `fitness-world.docx`, `gym.jpeg`, `WhatsApp Image ... .jpeg` — reference
  material (branding/photos). Not loaded by the app.
